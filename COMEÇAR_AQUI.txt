RJP TM TACTICS V1.8.0 — Android APK + WebApp — PT-PT

NOVO: TREINO + > EVOLUÇÃO ★
Acompanha a classificação geral estimada (com base no REC), as estrelas
individuais em atributos 19/20 e um histórico datado do treino de cada jogador.
As datas são apenas intervalos orientativos se existir histórico suficiente.

COMPILAR NO GITHUB
1. Extrai o ZIP no teu dispositivo.
2. Coloca todos os ficheiros na raiz do repositório RJP-TM-Tactics,
   incluindo a pasta oculta .github e as pastas src, tests e android-custom.
3. Faz Commit changes.
4. Actions > Compilar APK Android - RJP TM Tactics > Run workflow.
5. Terminada a compilação com sucesso, abre Artifacts e descarrega a APK.
6. Não é necessário instalar versões anteriores (1.4, 1.5, 1.6, 1.7).

ATUALIZAÇÃO/REINSTALAÇÃO
Antes de desinstalar, dentro da APP abre Opções > Backup completo > Exportar tudo.
Na nova instalação abre Opções > Restaurar backup completo.
Se a APK nova não usar a mesma chave da anterior, é necessário desinstalar;
isso elimina normalmente os dados locais. A chave persistente é opcional
para compilar APKs de teste, mas essencial para atualizar sem desinstalar.
