1) Extrai o ZIP e envia todos os ficheiros para a raiz do repositório GitHub.
2) Inclui a pasta oculta .github/workflows.
3) Antes de compilar, configura UMA vez a chave de assinatura em GitHub Secrets,
   seguindo ASSINATURA_E_ATUALIZACOES.md. O workflow bloqueia sem essa chave.
4) GitHub → Actions → Compilar APK Android - RJP TM Tactics → Run workflow.
5) Depois de sucesso → Artifacts → RJP-TM-Tactics-APK-Android → app-debug.apk.
6) Para WebApp: Settings → Pages → Source GitHub Actions; fluxo 'Publicar RJP TM Tactics'.

DADOS ANTERIORES: appId pt.rjp.tmtactics, chave de storage rjp_tm_tactics_v1.
Se a APK V1.3 instalada tiver sido assinada com outra chave, não pode ser instalada
por cima; exporta o plantel e as táticas, reinstala e volta a importar os backups.
Depois dessa migração, guarda a chave para todas as futuras atualizações.
